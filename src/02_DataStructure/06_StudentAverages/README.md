# 🎓 Student Score Manager

## What It Does
Manage student scores with file persistence (saves between sessions). Full CRUD: Add, View All, View by ID, Delete.

## Tech Stack
C# • .NET • File I/O • Enums • Clean Architecture

## Features
- ✅ Add student with ID and multiple scores
- ✅ View all students (formatted table)
- ✅ View single student by ID
- ✅ Delete student with confirmation
- ✅ Automatic grade calculation (A-F)
- ✅ File persistence (Students.txt)
- ✅ Unit tests included

## How to Run
```bash
dotnet run --project StudentScore/Program.cs
