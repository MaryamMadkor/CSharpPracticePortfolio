# ❌⭕ Ultimate Tic-Tac-Toe

## What It Does
Supports BOTH standard 3x3 AND 9x9 "Ultimate" Tic-Tac-Toe where each cell is a full 3x3 game.

## Tech Stack
C# • .NET • 2D Arrays • Enums • Clean Architecture

## Features
- ✅ 3x3 mode (standard)
- ✅ 9x9 Ultimate mode (9 sub-games)
- ✅ 8 win condition checks (rows, columns, diagonals)
- ✅ Color-coded console UI

## How to Run
```bash
dotnet run --project TicTacToe/Program.cs
