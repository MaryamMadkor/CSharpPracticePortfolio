# 🪨 Rock Paper Scissors (Pro Edition)

## What It Does
Play Rock Paper Scissors against AI with full session statistics and game history.

## Tech Stack
C# • .NET • Dependency Injection • Clean Architecture • Unit Tests

## Features
- ✅ Play against AI (random choices)
- ✅ Track wins/losses/draws per session
- ✅ View game history table
- ✅ Color-coded console UI
- ✅ Custom Unit tests (Player Win, PC Win, Draw)

## How to Run
```bash
dotnet run --project RockPaperScissors/Program.cs
