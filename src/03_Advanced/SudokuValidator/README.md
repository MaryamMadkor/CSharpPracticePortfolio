# 🔢 Sudoku Validator

## What It Does
Validates complete Sudoku boards (rows, columns, 3x3 boxes). Shows EXACTLY where duplicates are.

## Tech Stack
C# • .NET • 2D Arrays • Unit Tests

## Features
- ✅ Validates all 9 rows (no duplicates 1-9)
- ✅ Validates all 9 columns
- ✅ Validates all 9 boxes (3x3 sub-grids)
- ✅ Returns ALL duplicates with positions
- ✅ Custom Unit tests included

## How to Run
```bash
dotnet run --project SudokuValidator/Program.cs
